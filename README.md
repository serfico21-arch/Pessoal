# Painel do Corretor — Sérgio Costa (FCosta)

Este repositório é o **site pessoal de ferramentas** do Sérgio Costa, corretor de imóveis
(CRECI-SP · CNAI 52708) e pastor da OBPC Jardim São Fernando.

**Endereço do site:** https://serfico21-arch.github.io/Pessoal/

Abra esse endereço no celular ou no computador. A primeira página (o **Painel**) tem botões
para todas as ferramentas. No celular, dá para "Adicionar à tela inicial" e usar como aplicativo.

---

## Como editar uma página (passo a passo, sem programar)

1. Entre em https://github.com/serfico21-arch/Pessoal
2. Clique no nome do arquivo (por exemplo `calculadora-itbi.html`).
3. Clique no **lápis** ✏️ (canto de cima, à direita) para editar.
4. Aperte **Ctrl+F** e procure o texto que quer mudar (ex.: um telefone).
5. Troque só o texto. Não apague sinais como `<`, `>`, `"`, `{`, `}`, `;`.
6. Clique em **Commit changes** (verde) para salvar.
7. Espere 1 a 2 minutos e recarregue a página do site.

**Deu errado?** Abra o arquivo no GitHub, clique em **History** (Histórico), escolha a versão
anterior e volte para ela. Nada se perde: o GitHub guarda todas as versões.

Cada página `.html` tem, logo no começo, um bloco **AJUDA** explicando o que ela faz,
onde os dados ficam guardados e como editar.

### Onde ficam os dados que eu digito?
A maioria das ferramentas guarda os dados **no próprio celular/navegador** (não na internet).
Isso quer dizer:
- Os dados do celular **não aparecem** no computador, e vice-versa.
- Se limpar o histórico/dados do navegador, eles **somem**.
- Quando a página tiver botão de **Exportar / Backup**, use de vez em quando.

### Por que os arquivos não estão em pastas?
O site é publicado pelo **GitHub Pages**. Se um arquivo mudar de pasta, o endereço dele muda e
**os links que você já mandou no WhatsApp param de abrir**, além dos atalhos no celular.
Por isso os arquivos continuam na raiz, e a organização é feita por este guia e pelo Painel.

## Vídeos da TV FCosta (arquivos `v-...`)

A página `tv-fcosta.html` mostra os vídeos dos imóveis. Cada vídeo tem:
- `v-CODIGO.html` → a página que você compartilha no WhatsApp/Facebook;
- `v-CODIGO.jpg`, `v-CODIGO-p.jpg`, `v-CODIGO-og.jpg` → as imagens de capa
  (a `-og` é a que aparece na prévia do WhatsApp);
- `v-tXXXXX.mp4` → o vídeo em si.

**Não renomeie nem apague** esses arquivos se o link já foi compartilhado.
